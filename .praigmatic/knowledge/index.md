# Knowledge Graph

This directory accumulates domain knowledge artifacts during development.
Each file captures a specific area of understanding about the codebase,
architecture, or domain.

## Purpose

Knowledge artifacts prevent context loss across sessions and enable
agents to build on prior understanding. Files here are loaded by the
planner before creating new plans.

## Adding Knowledge

- Each file covers one topic or area
- Use clear, descriptive names
- Update relevant files when understanding evolves
- Empty the `index.md` is not helpful — write actual content when needed
