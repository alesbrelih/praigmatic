# PrAIgmatic Knowledge Base

This directory is the project's structured brain — separating knowledge from OpenCode engine configuration.

## Structure

- `plans/` — Implementation plans (active and archived)
- `knowledge/` — Domain knowledge artifacts accumulated during development
- `decisions/` — Architectural and technical decision records

## Purpose

The `.opencode/` directory holds engine configuration (agents, tools, commands, skills, reference docs).
The `.praigmatic/` directory holds project-specific intelligence — plans, decisions, and accumulated domain knowledge.
